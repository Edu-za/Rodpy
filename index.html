Lesson 1 · Print

Say hello with print()

In Python, print() shows a message on the screen. Put your words inside quotes. 

# This shows Hello, PyPal!
print("Hello, PyPal!")
Lesson 2 · Variables

Boxes that remember things

A variable is a named box. You put a value in it with =, then use the name later. 

# name holds a word, age holds a number
name = "Ada"
age = 10
print(name)
print(age)
Lesson 3 · If

Choose a path with if

An if statement runs code only when something is true. Indent the next line with spaces — Python cares about that! 

score = 9
if score > 5:
    print("You win!")
